«ВТОРОЕ МНЕНИЕ» (second-justice)

Прототип веб-интерфейса системы, которая даёт судье «второе мнение» при
назначении наказания по уголовному делу: проверяет проект приговора на
соответствие санкции статьи УК РФ, правилам Общей части и разъяснениям
Верховного Суда РФ, сравнивает наказание с практикой по схожим делам и
формирует заключение. Решений не принимает и судью не заменяет — выводы
справочные.

Пользователь: судья суда первой инстанции, проверяющий проект приговора перед
вынесением. Интерфейс в стиле судебных информационных систем, по умолчанию
русский.

Что можно делать: загрузить проект судебного акта (.docx/.pdf) или взять
демо-дело; посмотреть извлечённые параметры дела с оценкой достоверности;
получить проверки соответствия с вердиктом, расчётом и ссылкой на норму;
сравнить наказание со статистикой по аналогичным приговорам; распечатать
заключение. Есть личный кабинет, база решений, справочник практики, архив
заключений. Размер наказания можно менять — проверки и статистика
пересчитываются сразу. Интерфейс на русском и английском языках, переключатель
RU / EN в шапке.

Технологии: Next.js 15, React 19, TypeScript, Tailwind CSS, Zustand, Recharts;
шрифты ParaType. Только открытое и отечественное ПО.

Границы: реализован только фронтенд. Бэкенда, ML и реальной базы решений нет;
извлечение из произвольного документа имитируется, правовые данные и выборка
приговоров — подготовленные наборы.
