# Состав программного обеспечения

Документ подтверждает соблюдение требования о приоритете отечественного
программного обеспечения и решений с открытым исходным кодом.

## Отечественные компоненты

Шрифтовые гарнитуры PT Serif, PT Sans и PT Mono разработаны российской
компанией ParaType (Москва) в рамках программы «Общественные шрифты»
и распространяются по свободной лицензии SIL Open Font License.
Гарнитуры покрывают полный набор символов русского языка и языков народов
Российской Федерации.

Гарнитуры покрывают латиницу наравне с кириллицей, поэтому английская версия
интерфейса не требует отдельных шрифтов.

## Проприетарные и платные компоненты

Отсутствуют. Все зависимости распространяются по разрешительным лицензиям
(MIT, ISC, Apache-2.0, OFL), допускающим свободное использование,
модификацию и распространение, включая использование в государственных
информационных системах.

## Внешние сервисы

Прототип не обращается к внешним сервисам во время работы. Загруженные
документы обрабатываются в браузере и никуда не передаются. Данные сеанса
хранятся в localStorage браузера.

Единственное внешнее обращение происходит на этапе сборки: Next.js
загружает файлы шрифтов ParaType с Google Fonts и встраивает их в сборку,
после чего приложение работает без обращений к сети. Для полностью
изолированной сборки шрифты подключаются локальными файлами через
`next/font/local` — файлы доступны на сайте ParaType по той же лицензии.

## Импортозамещение при развёртывании

Прототип не содержит компонентов, препятствующих развёртыванию на
отечественном стеке:

- операционная система: любая из реестра российского ПО с поддержкой
  Node.js 20 (Astra Linux, «Ред ОС», ALT Linux);
- веб-сервер: nginx (BSD-2-Clause) либо Angie (российская сборка nginx);
- контейнеризация: Docker или Podman (Apache-2.0);
- при разработке серверной части: PostgreSQL (PostgreSQL License) либо
  Postgres Pro, входящий в реестр российского ПО.

Клиентская часть работает в любом браузере на движке Chromium или Gecko,
включая «Яндекс Браузер» и «Атом».
