# Выбор языка RU/EN и отказ от второй темы

Дата: 2026-09-16
Статус: реализован

## 1. Задача

Добавить выбор языка интерфейса — русский и английский, по умолчанию русский —
и убрать игровое оформление «Арена» вместе с переключателем тем.

## 2. Объём перевода

Переводятся интерфейс и данные дела: параметры, проверки с расчётами,
заключение, справочник практики Верховного Суда РФ, база судебных решений,
профиль.

Два поля намеренно не переводятся:

- `Extracted.quote` — дословная цитата из проверяемого судебного акта;
- `Sanction.text` — текст санкции статьи УК РФ.

Перевод этих полей создавал бы видимость второго аутентичного текста закона или
документа. В английском интерфейсе они выводятся с пометкой «quoted in the
original language».

Изложения позиций Верховного Суда РФ переводятся: README и `lib/data/practice.ts`
прямо оговаривают, что это пересказ по содержанию, а не цитаты.

ФИО, суды и регионы транслитерируются, иначе кириллица протекает в английские
таблицы.

## 3. Архитектура

| Слой | Решение |
|---|---|
| Двуязычное значение | `LText = { ru, en }`, помощник `l(ru, en)` в `lib/i18n/text.ts` |
| Состояние | zustand + localStorage, `lib/i18n/store.ts` |
| Словарь интерфейса | `lib/i18n/ui.ts`: русский объект задаёт тип `Dictionary`, английский обязан его повторить |
| Форматирование | `createFormat(locale)` в `lib/format.ts` |
| Доступ из компонентов | хук `useI18n()` → `{ locale, t, tr, trAll, f }` |

Текстовые поля модели данных (`lib/types.ts`) имеют тип `LText`, поэтому
пропущенный перевод — ошибка типизации, а не находка на демонстрации.
Альтернатива с отдельным деревом английских данных отвергнута: два параллельных
дерева расходятся молча.

Модули, собирающие строки на лету (`lib/rules.ts`, `lib/stats.ts`,
`lib/api/analysis.ts`), строят оба языка сразу — помощник `both((f, locale) => …)`
в `lib/rules.ts`. Иначе пересчитанная проверка была бы привязана к языку,
выбранному в момент правки.

Ключи фильтров (статья, регион в базе решений) остаются русскими строками: они
служат идентификаторами, и выбранный фильтр переживает переключение языка.

## 4. Гидратация

Статическая сборка отдаёт одну и ту же русскую разметку всем, поэтому язык по
умолчанию обязан совпадать с ней. Выбранный английский применяется сразу после
гидратации — тот же двухпроходный приём с флагом `hydrated`, что уже применён к
реестру дел. Inline-скрипт в `app/layout.tsx` до первой отрисовки выставляет
только атрибут `lang`: он нужен средствам доступности и переносу слов.

`<title>` и `description` остаются русскими: в статической сборке они одни на
весь сайт.

## 5. Удаление темы «Арена»

Удалены `lib/theme/`, `components/layout/ThemeSwitch.tsx` и около 200 строк
правил `[data-theme="arena"]` в `app/globals.css`; из `app/layout.tsx` убраны
гарнитуры Forum и Exo 2, из `docs/stack.md` — их описание. Блок `@media print`
сократился: возвращать судебную палитру больше не требуется, остаётся только
белый фон страницы. Подписи, которые раньше зависели от темы
(`lib/theme/labels.ts`), переехали в словарь интерфейса.

## 6. Структура данных

`lib/data/cases.ts` (1290 строк) разбит на каталог `lib/data/cases/` — по файлу
на дело плюс `types.ts` и `index.ts`. После удвоения текста один файл стал бы
нечитаемым.

## 7. Проверка

- `npx tsc --noEmit`, `npx next lint`, `npm run build` — без ошибок;
- проход по всем экранам в обоих языках на статической сборке, поднятой под
  подкаталогом, включая печатную форму заключения;
- живой пересчёт: 36 → 30 месяцев по делу 1-155/2026 снимает нарушение
  ч. 2 ст. 62 УК РФ и в русской, и в английской версии;
- консоль браузера чистая — расхождений разметки при гидратации нет.
